# Keymap Feature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a vim-inspired keyboard shortcut set (`/`, `[`, `]`, `t`, `g u`, `m`, `n`, `s`, `c`, `?`, `Esc`) and a warm-paper `?` help modal.

**Architecture:** Single consolidated `keydown` handler in `App.tsx` (replacing the old `⌘K` handler). Action functions are accessed via refs updated on every render to avoid stale closures. `showKeymapHelp` boolean state drives the modal.

**Tech Stack:** React 18, TypeScript, Vite. No new dependencies.

### Task 2: Replace ⌘K handler with consolidated keymap handler

**Files:**
- Modify: `src/App.tsx` (effects block, around the existing ⌘K `useEffect`)

- [ ] **Step 1: Remove the old ⌘K handler**

  ```tsx

    const handler = (e: KeyboardEvent) => {
      if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
        e.preventDefault();

        setRailSearchOpen(true);

  ```

- [ ] **Step 2: Insert the consolidated keymap handler in its place**

  At the same location (right after `// ── Effects ──...`), insert:

  ```tsx
  useEffect(() => {
    const pendingG = { current: false };

    const navigateDay = (delta: number) => {
      const d = new Date(selectedDateRef.current);
      d.setDate(d.getDate() + delta);
      const iso = `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
      setCurrentViewDate(d);
      setSelectedDate(iso);
    };

    const handler = (e: KeyboardEvent) => {
      const isInInput =
        e.target instanceof HTMLElement &&
        (e.target.tagName === 'INPUT' ||
          e.target.tagName === 'TEXTAREA' ||
          e.target.isContentEditable);

      if (e.key === 'Escape') {
        setRailSearchOpen(false);
        setSettingsOpen(false);
        setMobileSheet(null);
        setShowKeymapHelp(false);
        return;
      }

      if (isInInput) return;

      if (pendingG.current) {
        pendingG.current = false;
        if (e.key === 'u') goToFirstUnfinishedRef.current();
        return;
      }

      switch (e.key) {
        case 'g':
          pendingG.current = true;
          break;
        case '/':
          e.preventDefault();
          if (isMobile) {
            setMobileSheet(s => s === 'search' ? null : 'search');
          } else {
            setRailOpen(true);
            setRailSearchOpen(s => !s);
          }
          break;
        case '[':
          navigateDay(-1);
          break;
        case ']':
          navigateDay(1);
          break;
        case 't':
          goToTodayRef.current();
          break;
        case 'n':
          goToNextDayRef.current();
          break;
        case 'm':
          markCurrentAsReadRef.current();
          break;
        case 's':
          setSettingsOpen(prev => !prev);
          break;
        case 'c':
          cycleThemeRef.current();
          break;
        case '?':
          setShowKeymapHelp(prev => !prev);
          break;
      }
    };

    document.addEventListener('keydown', handler);
    return () => document.removeEventListener('keydown', handler);
  }, [isMobile]);
  ```

                          fontFamily: F.sans, fontSize: 12, color: theme.inkSoft,
                        }}>

                        </td>
                      </tr>
                    ))}
                  </tbody>
                </table>
